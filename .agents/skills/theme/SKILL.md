# Theme Skill

## Thematic direction

Use original names and concepts.

Allowed thematic words:

- graze
- spell
- spells
- choir
- sage
- Melchior
- Balthasar
- Casper
- ritual
- pattern
- orbit
- veil
- sigil

## Inspiration boundary

The project may be inspired by spell-card battles and dodge-first bullet patterns.

Do not copy official Touhou names, assets, locations, characters, or spell names.

Avoid directly using Touhou official terminology in code, UI, documentation, package names, or generated content unless explicitly requested.

The game should remain its own original work.

## Series structure

The title structure should preserve trilogy potential:

```txt
Graze Spells: Melchior
Graze Spells: Balthasar
Graze Spells: Casper
```
