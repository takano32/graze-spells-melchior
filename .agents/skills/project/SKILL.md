## Product direction

Graze Spells: Melchior is a React-first bullet-hell dodge game that will later support Expo mobile.

The game is dodge-first. The core experience is grazing, dodging, survival, readable spell patterns, clear hitboxes, and near-miss score feedback.

The first entry is **Melchior**, leaving room for later entries such as **Balthasar** and **Casper**.

## First playable milestone

Build toward this before adding large systems:

1. web page starts
2. player can move
3. bullets spawn
4. player hitbox is visible or debuggable
5. graze radius is visible or debuggable
6. grazing increases score
7. collision can end or reset the run
8. one named Melchior spell pattern exists

Suggested first spell name:

```txt
Melchior Opening: First Choir
```
