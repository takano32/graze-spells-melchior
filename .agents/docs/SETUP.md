# Setup

## Requirements

- Node.js
- pnpm

Corepack is not required.

Install pnpm globally if needed:

```bash
npm install -g pnpm
pnpm --version
```

## Install

```bash
pnpm install
```

## Run web app

```bash
pnpm dev:web
```

## Build web app

```bash
pnpm build:web
```

## Typecheck

```bash
pnpm typecheck
```
