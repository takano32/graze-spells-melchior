# Project Brief

## Title

**Graze Spells: Melchior**

## One-line pitch

A React-first bullet-hell dodge game where the main thrill is not shooting harder, but grazing closer.

## Core idea

Graze Spells: Melchior is a spell-pattern dodge game.

The player survives waves of bullets, reads patterns, moves precisely, and earns score by grazing near danger without being hit.

The first game is named **Melchior**, leaving room for later entries such as **Balthasar** and **Casper**.

## Target platform

Initial:

- Web
- React
- Vite
- TypeScript

Later:

- Expo
- Mobile
- shared platform-independent game core

## First milestone

A minimal playable web prototype.

Requirements:

- player movement
- visible playfield
- bullet spawning
- visible or debuggable hitbox
- visible or debuggable graze radius
- graze score
- collision reset or game over
- one named Melchior spell pattern
